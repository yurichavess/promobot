PROMOBOT



AI-powered e-commerce offer automation system that monitors promotions, filters offers, generates marketing copy using OpenAI, and automatically publishes offers to Telegram channels.

**FLUXO:**



Amazon API

&#x20;  ↓

Offer Collector

&#x20;  ↓

Filtering Engine

&#x20;  ↓

OpenAI Copy Generator

&#x20;  ↓

Telegram Publisher











\## Features



\- Amazon Product Advertising API integration

\- Real-time offer monitoring

\- Duplicate prevention system

\- AI-generated sales copy

\- Telegram channel automation

\- Configurable filtering engine

\- SQLite/PostgreSQL support

\- Async architecture







\## Tech Stack



\- Python

\- OpenAI API

\- Amazon PA-API

\- Aiogram

\- SQLAlchemy

\- APScheduler

\- SQLite/PostgreSQL
